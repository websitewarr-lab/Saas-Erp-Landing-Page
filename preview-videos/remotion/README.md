# Mossie ERP · Remotion previews

This standalone video project produces the eleven assets in the parent `preview-videos/` folder. See `../README.md` for the inventory and rendering instructions.

Use `npm run dev -- --port=3400` to open Studio, `npm run lint` for ESLint and TypeScript, and `npm run render` to render the complete set.

All animations use Remotion frame timing. There are no CSS animations, external font requests, live API calls or authenticated user data.
